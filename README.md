# School App — React + Firebase

Aplicación web desarrollada en 2020 como demo de exploración.
Integración de React con Firebase como backend en tiempo real.

## Stack técnico

- **Frontend:** React, SASS
- **Backend:** Firebase — Firestore, Firebase Functions, Auth
- **Estado:** Store centralizado
- **Estilos:** SASS con sistema de tema (theme.js)
- **Herramientas:** ESLint, Rutas con React Router

## Estructura

    src/
    ├── components/   # Componentes reutilizables
    ├── helpers/      # Funciones auxiliares
    ├── hooks/        # Custom hooks
    ├── store/        # Manejo de estado
    ├── stories/      # Storybook
    └── views/        # Vistas de la aplicación

## Contexto

Proyecto de exploración desarrollado en 2020.
Demuestra integración de React con servicios Firebase
y separación de responsabilidades desde etapas tempranas.
